# FilePan's decisions on top of freedesktop.org shared-mime-info, read by generate_mime_table.py.
#
#   ext <extension> <type> [<Kind>]  The type for an extension: an override, a tie-break or an
#                                    addition. The type must be a shared-mime-info type or alias,
#                                    unless it's an addition with an explicit kind.
#   kind <type> <Kind>               The kind of a type, where the derivation gets it wrong.
#   archive <type>                   A type FilePan's libarchive build can open (kind Archive).
#
# Kinds: Directory Image Video Audio Archive Apk Pdf Document Spreadsheet Presentation Text Code
# Font Other.
#
# The generator fails on a line that changes nothing, on an unknown type, and on an extension
# shared-mime-info maps to several types at the same weight without an ext line here. Types are
# lower-cased on output, as Android's MimeTypeMap spells them (it rejects upper case) and as
# Intent.normalizeMimeType makes them: intent filters compare types exactly, and Android tells
# apps to write theirs in lower case. A compound extension (tar.gz) must be an archive; other
# compressed files go by their last extension.

# --- Overrides: the spelling Android (MediaStore, the certificate installer) and the apps that
# receive open and share intents match on. Intent filters compare types exactly, so the
# shared-mime-info canonical name could drop apps from the chooser. All are its aliases.

ext heic    image/heic
ext mkv     video/x-matroska
ext mka     audio/x-matroska
ext wav     audio/x-wav
ext avi     video/avi
# Voice recordings: audio, not the 3GPP video type.
ext 3ga     audio/3gpp
# USB writer apps filter on it.
ext iso     application/x-iso9660-image
ext p12     application/x-pkcs12
ext pfx     application/x-pkcs12
# .tbz, .tar.bz and .bz are bzip2 in practice (libarchive finds bzip2 by its content), and
# libarchive can't read bzip1.
ext tbz     application/x-bzip2-compressed-tar
ext tar.bz  application/x-bzip2-compressed-tar
ext bz      application/x-bzip2
